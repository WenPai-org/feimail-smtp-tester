# fewmail-smtp-tester
## 开发中，请勿在生产环境使用

飞秒邮箱 FewMail SMTP Tester 自动定时测试 WordPress 邮件发送功能正常可用性。

SMTP 测试可帮助您主动监控多个 WordPress 网站的电子邮件送达率。这款插件专为开发者和代理机构设计，每周自动从子网站向父网站发送测试邮件，然后使用 IMAP 检查邮件送达情况。

子站点
每周向您选择的收件箱发送包含唯一令牌的测试电子邮件。

父站点
连接到您的收件箱并扫描测试电子邮件令牌以确认送达。

功能

选择“父站”或“子站”模式
设置发送测试电子邮件的日期和时间
手动测试电子邮件触发器
加密的 Gmail 应用密码存储（父站点）
电子邮件令牌跟踪
服务器时间显示
简单、轻量、易于设置
确保您的电子邮件不会悄无声息地失败——知道您的 SMTP 设置可靠地运行，您就可以放心了。
